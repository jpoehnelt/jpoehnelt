# Justin Poehnelt

Founder and CTO of [Helen’s Foundry](https://helensfoundry.com).

Helen’s Foundry is the strategic-intent layer for AI agents. It connects company strategy, product decisions, implementation work, pull requests, and code in a temporal knowledge graph—then gives agents that context over MCP and checks whether what they ship still matches the decisions behind it.

I lead the core build: bitemporal graph architecture, verification systems, MCP integrations, and the infrastructure that turns strategic context into enforceable engineering signals.
